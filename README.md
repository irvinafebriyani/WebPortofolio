## ✨ Fitur Website

Website portofolio ini memiliki beberapa bagian utama, yaitu:

1. **Beranda**  
   Menampilkan foto profil, nama, dan pengenalan singkat.

2. **Tentang Saya**  
   Berisi informasi dan perkenalan diri.

3. **Kemampuan**  
   Menampilkan beberapa kemampuan yang sedang dipelajari, seperti HTML, CSS, JavaScript, Bootstrap, dan Microsoft Office.

4. **Proyek Saya**  
   Menampilkan lima proyek atau hasil karya yang pernah dibuat.

5. **Kontak**  
   Menyediakan formulir untuk memasukkan nama, email, dan pesan.

6. **Footer**  
   Menampilkan informasi pembuat website dan hak cipta.

## 🛠️ Teknologi yang Digunakan

Berikut teknologi yang digunakan dalam pembuatan website ini:

- **HTML5** – Membuat struktur halaman website.
- **Bootstrap 5** – Mengatur tampilan dan membuat website responsif.
- **CSS Bootstrap** – Mengatur warna, tata letak, dan desain halaman.
- **JavaScript** – Menambahkan interaksi pada formulir kontak.

## 🚀 Cara Menjalankan Website

Ikuti langkah-langkah berikut untuk menjalankan website:

1. Unduh atau salin repositori ini.
2. Buka folder proyek menggunakan Visual Studio Code.
3. Pastikan file `index.html` dan folder `img` tersedia.
4. Pastikan semua gambar sudah berada di dalam folder `img`.
5. Buka file `index.html` menggunakan browser.
6. Website portofolio siap ditampilkan.
